Chapter 1 / Keeping the method

dev-skills

Decide what you want,
then let the agent run with it.

From requirement to a verified, mergeable PR: a set of Skills for coding agents. First, give the repository a verification environment the agent can start, operate and observe on its own. After that, one agent takes each requirement from start to finish and proves the result in the running app, and a model from another family verifies it independently. You step in at three points: confirm the decisions, confirm the acceptance criteria, and read the decision list before you merge.
