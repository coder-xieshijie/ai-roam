# 当前风格方向

更新：2026-09-24。适用范围：AI 游民首页，正式实现核对至 AI Roam `f8e1760`。早期提案与原话保留在第一轮讨论，后续决定见采用过程。

## 身份与表达目标

面向技术人的 AI 实践者与工具作者。内容包括 Agent 工具、开发方法、技术文章、工作与成长。希望工程表达清楚，同时让读者感受到作者和持续探索的过程。已有朱红机器人承担品牌识别。

## 本轮已经采用

| 决定 | 依据与边界 |
| --- | --- |
| 人文科技风 | 用户比较完整 A/B 后说“我会更喜欢后人文科技风”；后续明确批准完整 Anthropic Demo 更新主页 |
| 朱红探索线 | 从“暂定”发展为确认方案的一部分，随正式首页上线 |
| 从空白生成，线头随视野触达新点 | 用户对机器人预设轨道与跟随滞后的明确反例；正式页直接映射视野约 65% |
| 西文 Sans + Mono，中文文楷 + Plex | 用户要求试用 Anthropic Sans / Mono 并批准完整 Demo；具体语言回退为该 Demo 的实现方案 |
| Phosphor Regular | 随确认的人文方案采用；没有把这解释为用户单独比较后永久选定图库 |
| “开始探索” | 用户明确要求删去按钮前半句；正式页已修改 |

## 本轮未采用

- 藤蔓：喜欢生成机制，但植物气质与本人风格不搭。
- 机器人移动载体：预设轨道和章节追赶不符合连续阅读体验；品牌机器人仍保留。
- 瑞士编辑：助手曾首推，用户更喜欢人文方案；不能继续把首推当当前方向。
- 手绘游迹、开发者工作台、其他字体：保留探索依据，没有据此形成长期排斥规则。

## 可以暂时复用的原则

1. 喜欢参考的交互，不等于喜欢它的装饰主题。
2. 动效先服务阅读：线头跟随视野、后续内容保持空白、手机不挡正文。
3. 用真实中文、英文项目名、代码和日期一起比较字体；Sans / Mono 分工使用。
4. 用真实作品、判断和手记表达作者，不靠堆叠装饰替代内容。
5. 原型的个人偏好要经过真实内容与手机阅读验证；跨项目复用仍需验证。

这些是本案例支持的暂行原则。“清楚、有秩序、细节精致”等早期归纳仍是助手推断，不升级为用户亲自定义的品牌关键词。

## 仍未解决

- 项目与文章内页是否统一为人文科技风；当前仍沿用原布局。
- 探索线是否扩展到其他页面；没有批准全站铺设。
- 长文的字号、行宽与密度是否需要下一轮独立阅读测试。
- 品牌机器人在更多场景的使用频率，以及字体长期加载来源。

当前具体参数见[首页规范](ai-roam-homepage.md)。只在新决策有证据时更新状态，不将历史候选改写成“从未考虑”。
