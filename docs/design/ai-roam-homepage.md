## 色彩与材质

| 用途 | 正式值 |
| --- | --- |
| 暖纸背景 | `#F4F0E6` |
| 主文字 | `#3C3E34` |
| 次要文字 | `#737666` |
| 分隔线 | `#D8D2C3` |
| 朱红强调 | `#B75B42` |
| 主按钮 hover | `#924832` |

纸感来自轻微点状 CSS 背景；不依赖第三方纸张图片。留白、细分隔和局部绿色辅助字色共同组织页面。不要再使用早期朱红 Demo 的 `#F8F6F1` / `#C5543D` 作为正式值。

## 字体分工与来源

| 场景 | 西文 | 中文 / 回退 |
| --- | --- | --- |
| 标题 | Anthropic Sans | 霞鹜文楷 |
| 正文、导航、项目名 | Anthropic Sans | IBM Plex Sans SC |
| 代码、命令、日期、编号 | Anthropic Mono Web | IBM Plex Mono；中文落到 Plex Sans SC |

等宽用于需要比较列宽、缩进和符号的内容；没有把全页正文改成等宽。手写气质集中在中文标题，正文保持可读性。

- 正式页从 Anthropic 使用的公开 CDN 加载两款西文字体，并有本地回退；不依赖访客本机安装。
- 原设计仓库的历史实验保留 `local()` 加载，可显示缺失字体提示；不能把回退效果当 Anthropic 实测。
- 不分发 Anthropic 字体二进制，也不声称获得其开源再分发许可。
- 开源中文字体及 Plex Mono 为 WOFF2 子集，附各自许可。修改文案需重新检查字形覆盖。
- 原型固定来源见素材说明与来源清单；生产字体说明见[AI Roam README](https://github.com/coder-xieshijie/ai-roam/blob/f8e17602ce297abcac736b934177377450635d4d/README.md#首页设计与字体)。

## 图标、版式与组件

功能图标采用 Phosphor Regular 本地 SVG sprite，统一单色线性形式；品牌机器人用于身份识别，不再作为追赶章节的移动角色。A 版的 Remix 和早期三栏示意的 Lucide 仅为各自实验资源。

- 桌面内容最大宽度 1060px；品牌居中、导航和 GitHub 分置两侧。
- 首屏居中标题、作者信息、朱红胶囊按钮“开始探索”。
- 作品：Observer 界面展示，保留“合成示例数据”说明；补充四个工作流入口。
- 方法：手册式封面与代码标签，体现可复用开发方法。
- 写作：一张精选主卡片与两个紧凑入口；元信息不抢标题层级。
- 经历：短列表与旁注；开源贡献、最近记录和联系区衔接其后。
- 桌面交错图文与中央探索线；手机重排内容，探索线置于左侧。

## 探索线行为

来源：[home-trail.js](https://github.com/coder-xieshijie/ai-roam/blob/f8e17602ce297abcac736b934177377450635d4d/assets/home-trail.js)。

1. 进入有效绘制区域前没有预设可见轨道，线头隐藏。
2. 绘制前沿直接对应视野高度约 65%，不使用追赶式缓动。
3. 未经过的主线、分支和节点均隐藏；经过标题才显现连接。
4. 反向滚动收回；回到起点可以重新体验。
5. 字体加载、布局尺寸变化后重算路径，避免标题与连接错位。
6. `prefers-reduced-motion` 下展示静态完整路径并隐藏移动线头。

以上是首页已实现行为；验证的范围与未验证部分见验证记录。内页仍使用原来的 `site.css`，不能用这份规范声称整站已经统一。
