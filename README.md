# xieshijie-crab

谢世杰「AI游民」的个人落地页。

## 本地预览

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173>。

## 结构

- `index.html`：页面、样式与交互，零构建依赖
- `assets/crab.png`：移动工作舱寄居蟹角色图

## 页面内容

页面使用公开、已脱敏的个人定位信息，围绕三条主线展开：

- 更会用：AI Agent、Skills、工作流、评测与安全
- 更会判断：工具选择、真实验证与长期影响
- 更会成长：AI 岗位、能力积累与职业杠杆
